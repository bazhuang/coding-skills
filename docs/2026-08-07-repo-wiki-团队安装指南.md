# repo-wiki skill 团队安装指南

## 这个 skill 是干什么的

`repo-wiki` 用于为本地代码仓库自动生成项目文档（项目百科）：从文件树和 README 出发，生成包含 Mermaid 图表、源码引用、数据表格的中文 Markdown 文档，输出到仓库的 `docs/wiki/` 目录。

## 安装方法

把下面这句话原样发给你在用的 AI 编程工具（OpenCode / Claude Code / Codex / Cursor 等均可）：

> http://10.3.81.85/skills/wiki/ ，全局安装一下这个skill

工具会自己访问该地址、下载全部文件并装到本机的全局 skill 目录——Windows、macOS、Linux 都适用，不需要手动跑任何脚本。

装完后**重启一下工具**（skill 是启动时加载的），然后就能用了。

## 验证安装

随便打开一个代码仓库，对工具说"为这个仓库生成项目 wiki"，或输入 `/repo-wiki`，能触发即为安装成功。

## 注意事项

- 电脑需能访问 `10.3.81.85`（与文件服务器在同一内网，或通过 VPN 连通）。
- 如果访问不通，联系文档维护者确认服务是否在线。
