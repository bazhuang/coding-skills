# App-Generate Skill (通用版)

基于本体图谱进行数据建模、架构设计、详细设计的通用开发流程工具。

## 核心特性

- **通用性**：适用于任意业务领域的本体图谱
- **动态化**：表名、包路径、关联表均从ontology动态生成
- **可配置**：支持用户自定义项目参数

## 如何触发

在 CodeBuddy IDE 中，以下场景会自动触发此 skill：

### 触发关键词

| 场景 | 触发语句 |
|------|----------|
| 数据建模 | "根据 ontology 图谱生成 DDL"、"做数据库建模" |
| 架构设计 | "做架构设计"、"输出架构设计文档" |
| 详细设计 | "做详细设计"、"输出详细设计文档" |
| 本体建模 | "基于本体建模"、"进行 ontology 建模" |
| 全流程 | "从头开始"、"重新进行建模" |

### 示例对话

```
用户: 基于 ontology.json 做数据库建模
      → 自动触发 app_generate skill

用户: 根据图谱做架构设计
      → 自动触发 app_generate skill

用户: 进行本体建模
      → 自动触发 app_generate skill
```

## 工作流程

```
阶段一: 本体图谱Schema解析
   ↓
阶段二: 数据建模 (DDL生成)
   ↓
阶段三: 头脑风暴 (架构师决策)
   ↓
阶段四: 架构设计 (概要设计)
   ↓
阶段五: 详细设计
   ↓
阶段六: 代码生成
```

## 适用场景

- 根据 ontology 图谱 schema 进行 DDL 生成
- 任意业务领域的数据建模
- 数据库建模、架构设计、详细设计全流程

## 用户配置项

用户在开始使用前可以提供以下配置（可选）：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `base_package` | 基础包路径前缀 | `com.example` |
| `db_name` | 数据库名称 | `app_db` |
| `table_prefix` | 表名前缀 | 无 |
| `author` | 文档作者 | `AI` |

## 主要改进（通用版）

1. **移除硬编码**：不再绑定特定项目或业务领域
2. **动态生成**：
   - 表名从对象code动态生成（下划线命名）
   - 包路径从用户配置动态生成
   - 关联表从edges关系动态生成
3. **通用议题**：头脑风暴阶段使用通用讨论议题
4. **模板通用化**：架构和详细设计模板使用占位符

## Ontology格式要求

Ontology文件应为JSON格式，包含以下核心结构：

```json
{
  "objects": [...],
  "edges": [...],
  "rules": [...],
  "behaviors": [...],
  "sop": [...]
}
```

详细格式说明请参考 SKILL.md 文件。
