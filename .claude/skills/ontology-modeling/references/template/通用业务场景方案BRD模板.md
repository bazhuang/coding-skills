## 1. 业务背景

供需匹配是企业运营的核心场景，需要在指定周期内完成资源调配、服务交付、客户需求满足的全链条匹配决策，确保在多重约束条件下实现业务价值最大化。

---

## 2. 核心目标

| 编号 | 目标 | 说明 | 优先级 |
|:---:|:---:|------|:-----:|
| G1 | **价值最大化** | 在满足客户需求的前提下，最大化企业收益 | 高 |
| G2 | **约束满足** | 遵守资源容量、服务能力、客户优先级等多重业务约束 | 高 |
| G3 | **方案可执行** | 生成明确的资源分配、服务路径、客户交付计划 | 中 |

---

## 3. 业务流程

1. 制定经营计划（目标、策略）
2. 录入供给侧数据（资源容量、成本、合约条款）
3. 录入需求侧数据（客户需求、优先级、灵活性）
4. 录入服务能力数据（处理能力、最低服务量、服务成本）
5. 系统自动匹配，生成最优分配方案
6. 审核确认，输出执行方案

---

## 4. 价值计算公式

```
收益 = 服务收入
     - 资源获取成本
     - 服务交付成本
     - 资源闲置成本（未达最低使用量时触发）
     - 需求缺口成本（客户需求未满足时触发）
     - 服务能力浪费成本（未达最低服务量时触发）
```

---

## 5. 关键约束

| 编号 | 维度 | 约束规则 | 违反后果 |
|:---:|:---:|---------|---------|
| C1 | **需求侧** | 实际交付量 ≤ 计划需求量，高优先级客户优先满足 | 产生需求缺口成本 |
| C2 | **供给侧** | 资源使用量 ≤ 可用总量，未达最低使用量产生闲置成本 | 产生资源闲置成本 |
| C3 | **服务能力侧** | 服务处理量 ≤ 最大处理能力，未达最低服务量产生浪费成本 | 产生服务浪费成本 |
| C4 | **关联** | 供给接入点必须连接服务起点，服务终点必须连接需求接收点 | 方案不可执行 |

| 编号 | 对象 | 说明 |
|:---:|------|------|
| O1 | **经营计划** | 周期目标与策略，指导整体匹配方向 |
| O2 | **供给池** | 上游资源信息，包含容量、成本、合约条款 |
| O3 | **需求池** | 下游客户需求，包含需求量、优先级、灵活性 |
| O4 | **服务能力池** | 中间环节处理能力，包含容量上限、最低服务量、服务成本 |
| O5 | **匹配结果** | 最终的分配方案，包含资源分配、服务路径、客户交付量 |

## 8. 业务规则

| 编号 | 维度 | 规则描述 |
|:---:|:---:|---------|
| BR1 | 需求侧 | 实际交付量 ≤ 计划需求量 |
| BR2 | 需求侧 | 高优先级客户必须满足 |
| BR3 | 需求侧 | 灵活客户在最低量与计划量之间调配 |
| BR4 | 供给侧 | 使用量 ≤ 可用总量 |
| BR5 | 供给侧 | 未达最低使用量时产生闲置成本 |
| BR6 | 服务能力侧 | 处理量 ≤ 最大处理能力 |
| BR7 | 服务能力侧 | 未达最低服务量时产生浪费成本 |
| BR8 | 关联 | 供给接入点必须连接服务起点 |
| BR9 | 关联 | 服务终点必须连接需求接收点 |

## 9. 业务行为

| 编号 | 行为 | 说明 |
|:---:|------|------|
| A1 | 制定经营计划 | 确定周期目标、策略和原则 |
| A2 | 录入/更新数据 | 录入或修改供给池、需求池、服务能力池数据 |
| A3 | 生成匹配结果 | 系统自动计算最优分配方案 |
| A4 | 审核确认 | 业务人员检查并确认匹配结果 |
| A5 | 查询数据 | 查看各类业务数据和匹配方案 |
| A6 | 删除无效数据 | 清理不再使用的数据或方案 |

## 10. SOP 操作流程

| 步骤 | 操作角色 | 操作描述 |
|:---:|:------:|---------|
| 1 | 业务人员 | **制定经营计划**：确定周期内的匹配目标和策略 |
| 2 | 业务人员 | **录入业务数据**：录入供给侧、需求侧、服务能力数据 |
| 3 | 系统 | **自动生成匹配方案**：根据计划和各池数据计算最优方案 |
| 4 | 业务人员 | **审核确认方案**：检查结果是否满足业务要求，确认后生效 |
| 5 | 系统 | **输出执行方案**：输出可执行的方案供落地 |

## 11. 术语说明

| 术语 | 说明 |
|------|------|
| 供给池 | 上游可供调配的资源集合 |
| 需求池 | 下游客户的需求集合 |
| 服务能力池 | 连接供给与需求的中间处理环节 |
| 闲置成本 | 资源未被充分使用时产生的额外成本 |
| 缺口成本 | 客户需求未被满足时产生的额外成本 |
| 浪费成本 | 服务能力未被充分利用时产生的额外成本 |
