# DSL 非线性优化规则

本文件给出对运筹 DSL 进行非线性识别、转化和重构时的规则。

## 1. 非线性识别

遍历目标函数和所有约束，识别以下要素：

- 分段函数
- 非光滑函数，如 `max`、`min`、`abs`、`sign`
- 变量乘积
- 指数或对数项
- 分式、根号
- 条件判断嵌套

每一项都要记录：

- 所在位置
- 原表达式
- 变量依赖
- 非线性类型
- 凸性或可 reformulate 性

## 2. 转化优先级

优先级如下：

1. 严格等价的线性化或 MIP reformulation
2. 严格等价但会增加少量辅助变量和约束的 reformulation
3. 有明确误差界的近似

如果不能保证等价性，必须明确说明。

## 3. 常见转化策略

### 分段函数

- 引入区间选择变量
- 建立分段变量与区间归属的连接约束
- 补充互斥或覆盖约束

### 非光滑函数

例如 `max(0, x-y)`：

- 引入辅助变量
- 用线性不等式约束辅助变量与原表达式的关系

### 二元变量与连续变量乘积

例如 `z = x * y`，其中 `y` 为 0-1 变量：

- 利用上下界构建标准线性化约束

### 其他非线性项

- 只有在理论依据清楚时才采用近似
- 近似时必须说明误差来源和影响

## 4. 重构要求

重构后的 DSL 需要完整更新：

- `decision_vars`
- `objective`
- `constraints`
- `solve_config`

保留未受影响的模块，避免无关改动。

## 5. 验证要求

至少说明：

- 与原模型等价或近似的依据
- 新增变量数和约束数的大致影响
- 求解效率影响
- 可能失效的边界条件

## 6. 输出格式

- 先按“识别 -> 转化 -> 重构 -> 验证”组织分析
- 然后输出完整 DSL JSON
- 最终 JSON 必须满足 DSL schema
